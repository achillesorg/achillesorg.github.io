# Achilles website

This is the GitHub Pages source for [achilles.mandrusia.tech](https://achilles.mandrusia.tech).

- `index.html` contains the page and its styles. There is no build step.
- `assets/` contains the Signal branding supplied by the Achilles brand pack. Do not redraw or distort the logo.
- `CNAME` sets the custom domain for GitHub Pages.

To edit the site, change `index.html` and push to `main`. GitHub Pages deploys the updated files.
